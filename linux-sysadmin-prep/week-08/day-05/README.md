# Week 08 / Day 05 — Capstone: build, harden, and document a server

## Objectives

- Combine every week into one end-to-end build
- Document what you did so someone else can repeat it
- Prove the result with evidence, not assertions

## Commands in scope

- `everything`

## Exercises

1. Provision a VM and take it from fresh install to serving an application.
2. Apply the Week 08 hardening baseline and show evidence for each item.
3. Add monitoring, log rotation, and a tested backup+restore.
4. Write a runbook another admin could follow without asking you questions.

## Solution

See [`solution.sh`](solution.sh). Work the exercises first — reading the
answer teaches you far less than getting stuck does.
