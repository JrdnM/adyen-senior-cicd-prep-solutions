# Week 08 / Day 01 — Hardening a fresh server

## Objectives

- Apply a baseline hardening checklist
- Reduce attack surface
- Keep the system patched

## Commands in scope

- `ssh hardening`
- `unattended-upgrades`
- `fail2ban`
- `systemctl`
- `ss`

## Exercises

1. List the services listening on all interfaces and justify or disable each.
2. Enable automatic security updates.
3. Install and configure fail2ban for SSH.
4. Write a ten-item baseline checklist for a new host.
