# Week 08 / Day 03 — Systematic troubleshooting

## Objectives

- Work a problem from symptom to cause instead of guessing
- Use a repeatable order of investigation
- Know when to stop and escalate

## Commands in scope

- `journalctl`
- `systemctl`
- `ss`
- `df`
- `dmesg`
- `strace`

## Exercises

1. Write down your standard order of checks for 'the site is down'.
2. A service fails to start. Give the first four commands you run.
3. Find what a stuck process is blocked on.
4. Check the kernel ring buffer for hardware or OOM events.

## Solution

See [`solution.sh`](solution.sh). Work the exercises first — reading the
answer teaches you far less than getting stuck does.
