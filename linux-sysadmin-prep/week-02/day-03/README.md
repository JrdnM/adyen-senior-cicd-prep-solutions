# Week 02 / Day 03 — sed and awk basics

## Objectives

- Do non-interactive search-and-replace with sed
- Select and reformat columns with awk
- Know when to reach for a real script instead

## Commands in scope

- `sed`
- `awk`

## Exercises

1. Replace every occurrence of `foo` with `bar` in a copy of a config file, in place, keeping a backup.
2. Delete all comment and blank lines from `/etc/ssh/sshd_config`.
3. Print the total of the third column of a whitespace-separated file.
4. Print `/etc/passwd` as `username -> home directory`.

See [`solution.sh`](solution.sh). Work the exercises first — reading the
answer teaches you far less than getting stuck does.
