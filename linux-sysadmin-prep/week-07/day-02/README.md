# Week 07 / Day 02 — Loops, functions, and arrays

## Objectives

- Iterate over files and command output safely
- Factor logic into functions
- Use arrays instead of word-splitting strings

## Commands in scope

- `for`
- `while read`
- `functions`
- `arrays`
- `IFS`

## Exercises

1. Loop over every `.conf` file in a directory, including names with spaces.
2. Read a file line by line without mangling backslashes or trailing whitespace.
3. Write a function that returns a value to the caller.
4. Build a command's arguments in an array and run it.
