# Week 04 / Day 01 — Package management (apt and dnf)

## Objectives

- Install, upgrade, and remove packages
- Query which package owns a file
- Understand repositories and pinning basics

## Commands in scope

- `apt`
- `dpkg`
- `dnf`
- `rpm`
- `apt-file`

## Exercises

1. Update the package index and list which installed packages have upgrades available.
2. Find which package provides `/usr/bin/dig`.
3. Show the files installed by a package, and its dependencies.
4. Remove a package but keep its configuration files, then purge it completely.

## Solution

See [`solution.sh`](solution.sh). Work the exercises first — reading the
answer teaches you far less than getting stuck does.
