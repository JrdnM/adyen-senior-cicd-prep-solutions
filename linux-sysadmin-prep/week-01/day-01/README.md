# Week 01 / Day 01 — Navigating the filesystem

## Objectives

- Explain the Filesystem Hierarchy Standard at a high level
- Move between directories using absolute and relative paths
- List files including hidden ones and read `ls -l` output

## Commands in scope

- `pwd`
- `cd`
- `ls`
- `tree`
- `file`
- `stat`

## Exercises

1. Print your current directory, then move to `/etc` using an absolute path and back to home with a single command.
2. List everything in `/var/log` including hidden entries, sorted by modification time, newest first.
3. For `/etc/hostname`, report its size, owner, and last-modified time in one command.
4. Explain in one sentence each what `/etc`, `/var`, `/usr`, `/opt`, and `/tmp` hold.
