# Week 01 / Day 03 — Getting help: man, info, and --help

## Objectives

- Find the right documentation without reaching for a search engine
- Read a man page's SYNOPSIS notation correctly
- Search across man pages by keyword

## Commands in scope

- `man`
- `apropos`
- `whatis`
- `info`
- `help`
- `type`
- `which`

## Exercises

1. Find which man section documents the `printf` *library call* versus the *command*.
2. Search all man pages for anything mentioning 'schedule'.
3. Determine whether `cd`, `ls`, and `[` are shell builtins or external binaries.
4. From `man ls`, explain what the square brackets in the SYNOPSIS mean.
