# Week 06 / Day 01 — Interfaces and addressing

## Objectives

- Inspect and configure IP addresses and routes
- Read CIDR notation
- Make configuration persistent

## Commands in scope

- `ip`
- `nmcli`
- `netplan`
- `CIDR`

## Exercises

1. Show every interface with its addresses and state.
2. Add a temporary secondary address, then remove it.
3. Show the routing table and identify the default gateway.
4. How many usable hosts are in a /26?
